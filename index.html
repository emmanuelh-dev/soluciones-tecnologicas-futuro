Automatización DevOps

Soluciones Tecnológicas del Futuro

Bienvenido

Este es el portal de presentación del proyecto de automatización DevOps para una empresa fintech en expansión. La plataforma implementa mejores prácticas de entrega continua, infraestructura como código y seguridad integrada.

✓ Servicio Activo en Puerto 8082

Pilares del Proyecto

Infrastructure as Code

Plantillas AWS CloudFormation para aprovisionamiento automatizado de EC2 y S3.

CI/CD Pipeline

GitHub Actions con validación automática, construcción Docker y despliegue vía SSH.

Automatización Bash

Scripts interactivos para configuración de entorno y mantenimiento del sistema.

DevSecOps

Análisis estático, validación de seguridad y monitoreo integrado en el pipeline.

Contenedorización

Docker y Docker Compose para orquestación en red privada aislada.

Observabilidad

Integración con AWS CloudWatch para monitoreo y alertas automáticas.

Componentes Principales

setup_env.sh: Script interactivo de configuración del entorno Linux/Ubuntu.

aws_report.py: Automatización de inventario de recursos AWS usando Boto3.

template.yaml: Plantilla CloudFormation declarativa para infraestructura.

Docker & Docker Compose: Contenedorización y orquestación en red aislada.

GitHub Actions: Pipeline de validación, construcción y despliegue continuo.
